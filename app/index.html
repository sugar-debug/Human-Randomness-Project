How reliable is this?

The model is a logistic regression on 12 summary features (digit entropy, chi-square, repeats, runs, coin balance and so on). Across repeated cross-validation it was right about of the time on whole datasets, where guessing gives 50%. A single sequence pair is a lean, not proof: a careful human can look like a computer and a computer can look like a human. It was trained on one student sample, and it only accepts exactly 20 digits and 20 flips because several features depend on length.
